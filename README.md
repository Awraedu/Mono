# MONO. — The Power of Absolute Less.

**MONO.** is a premium, minimalist utility hub for Android, built with a focus on architectural design, precision typography, and multi-sensory feedback. It aggregates 100+ professional tools into a single, cohesive interface.

## ✨ Features

- **Architectural UI**: A high-end design system inspired by Vercel and OpenAI, using the **Geist** and **Geist Mono** font families.
- **Tactile Feedback System**: A custom-built haptic and audio engine that provides distinct mechanical "clicks", "ticks", and "impacts" for every interaction.
- **Dynamic Tool Library**: A real-time searchable and filterable collection of professional tools across 10+ categories.
- **Fluid Motion**: Premium letter-by-letter cascading animations and seamless transitions.
- **Themed Experience**: Full support for Dark and Light modes with adaptive branding and Lottie-based splash animations.
- **Smooth Geometry**: G² continuous rounded corners using the **Capsule** library for an "iOS-style" premium look.

## 🛠️ Tech Stack

- **Framework**: Jetpack Compose
- **Language**: Kotlin
- **Typography**: Geist Sans & Mono
- **Animation**: Lottie & Compose Animation API
- **Haptics**: Custom `TactileFeedback` engine (Vibrator + Synthesized AudioTrack)
- **Icons**: Tabler Icons

## 📂 Project Structure

- `core`: Central tool management and state logic.
- `features`: Feature-based modularization (Home, Library, Splash, Tools).
- `ui`: Shared components, theme tokens, and sensory assets.
